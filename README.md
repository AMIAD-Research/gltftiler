# GLTF Tiler

Toolbox to create and manage GLTF files for 3DTiles.

## Installation

Install `gltftiler` from sources:
```
git clone https://github.com/AMIAD-Research/gltftiler.git
cd gltftiler
pip install -e .
```

Or directly from github:
```
pip install git+https://github.com/AMIAD-Research/gltftiler.git
```

## Usage

`gltftiler` is a Python library that can be imported into other applications.
